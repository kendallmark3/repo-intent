# Why This Design

RepoIntent deliberately avoids starting as a hosted product or a large agent platform.

The hardest problem is not access to more infrastructure. It is **trustworthy repository reasoning**.

V1 therefore focuses on:
- structural orientation before deep reading;
- evidence-backed claims;
- explicit inference;
- contradiction detection;
- independent re-verification of important conclusions;
- measured evaluation against known repositories.

If V1 later struggles with scale, repeated context acquisition, cross-repo relationships, runtime behavior, or enterprise sources, those failures can justify code graphs, AST/LSP tooling, MCP, persistent indexing, or AWS.

Until then, complexity would make the demonstration larger without proving the core intelligence.
